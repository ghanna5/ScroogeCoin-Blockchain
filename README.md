# ScroogeCoin-Blockchain

Java projects from CPSC 459 (Blockchain Technologies) at Cal State Fullerton.

| Folder | What it does |
| --- | --- |
| `ScroogeCoin` | Transaction handler that validates transactions against a UTXO pool, plus a version that picks the set of transactions with the highest fees |
| `ConsensusFromTrust` | A compliant node that reaches consensus in a network that includes malicious nodes |
| `BlockChain` | A block chain that tracks forks, keeps the longest valid chain and maintains a UTXO pool for each block |

Each folder has the starter code and the completed version used for grading.
